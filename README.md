# Smart Web – سمارت ويب

موقع سمارت ويب لتصميم المواقع الإلكترونية: عرض الخدمات بأقسام، طلب عبر واتساب أو اتصال (+971503052551)، ولوحة إدارة لإضافة الخدمات وتعديلها.

## الملفات
- `index.html` – الموقع كاملاً (الإعدادات في `window.CONFIG` داخل الملف)
- `setup.sql` – إنشاء جدول الخدمات في Supabase (يُشغّل مرة واحدة)
- `logo/` – ملفات الشعار (فاتح، داكن، أيقونة) بصيغتي SVG و PNG

## إدارة الخدمات
اضغط «دخول الإدارة» أسفل الصفحة ثم «＋ إضافة خدمة».

- **قبل ربط Supabase:** الدخول برمز `ADMIN_PIN`، والخدمات المضافة تُحفظ على نفس الجهاز فقط.
- **بعد الربط:** الدخول بالبريد وكلمة المرور، والخدمات تظهر لكل الزبائن.

## ربط Supabase
1. أنشئ مشروعاً في supabase.com ثم شغّل `setup.sql` في SQL Editor.
2. Authentication ← Users ← Add user: أنشئ حساب الإدارة.
3. Project Settings ← API: انسخ Project URL و anon key إلى `SUPABASE_URL` و `SUPABASE_KEY` في `index.html`.

## النشر
Settings ← Pages ← Branch: `main` / `(root)` ← Save
